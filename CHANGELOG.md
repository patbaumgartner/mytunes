# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

Nothing has been released yet; everything below describes what 1.0.0 will contain.

## [Unreleased]

### Changed (this branch: `without-spring-boot`)

- Removed Spring Boot 4.1.1 and Spring Modulith 2.1.0; the object graph is wired by nine
  constructor calls in `main()`. The Wasm module shrinks from 16,051,547 to 1,292,751 bytes
  (12.4×), the `gzip -9` wire size from ~6.8 MB to 533,043 bytes, and in-browser startup from
  ~137 ms to ~20 ms. Module boundaries formerly verified by Spring Modulith are re-expressed
  as ArchUnit rules in `ModularityTests`, and the two `@TargetClass` substitutions
  (`StackWalker`, `System.console()`) became unnecessary and were deleted.

### Added

- The application: Spring Boot 4.1.1 + Spring Modulith 2.1.0 compiled to WebAssembly by GraalVM
  Web Image, running entirely in the browser — the DOM interface, audio control, persistence
  and event handling are all Java. No server-side application, no hand-written JavaScript
  beyond the two one-expression browser-global accessors.
- A station catalogue of 8 categories with 30 channels. Every category leads with a channel
  generated by `tools/generate-audio.py` and served with the application, so playback is
  always demonstrable offline; the remaining channels are live streams from SomaFM,
  Nightride FM and Radio Paradise, each verified to answer browsers with an audio content
  type and permissive CORS (`tools/generate-stations.py` re-runs that verification and
  proposes new candidates from the Radio Browser directory).
- Original animated artwork: five generated SVG landscapes with a declarative SMIL day-night
  cycle — the sun crosses the sky in about a minute, a cratered moon takes over travelling the
  same direction, stars come out towards midnight, clouds drift, birds glide, ripples play on
  the water, reeds sway, fireflies appear around midnight, and a pair of rabbits watches from
  the foreground.
- Persistent preferences (station, background, volume, mute) in `localStorage` behind a
  versioned schema; Media Session integration for lock-screen and media keys; a Document
  Picture-in-Picture mini player carrying the full transport (previous/play/next, mute,
  volume); keyboard shortcuts. Generated channels loop seamlessly.
- Serving: an unprivileged nginx container holding no JVM and no jar, with security headers,
  immutable caching and a health endpoint. The ~16 MB module is built with `-Os`, without
  debug annotations (`-Pwasm-debug` restores them), shrunk further by a `wasm-opt -Oz`
  pass in the container build, and delivered precompressed (`gzip -9` at build time,
  served via `gzip_static`) at ~6.8 MB on the wire.
- Verification: a JVM suite (unit, Spring context, modularity, architecture, and the
  zero-JavaScript constraint) plus an authoritative Playwright suite driving the built module
  in a real browser, with screenshots and console logs generated into `target/diagnostics/`
  and uploaded as a CI artifact.
- Automation and community health: CI with a from-scratch container build and browser tests
  against the image, a GitHub Pages deployment of the tested site and a Docker Hub publication
  of the tested image on every push to main, CodeQL, dependency review, Dependabot,
  contributing guide, security policy, code of conduct, and issue/pull request templates.
